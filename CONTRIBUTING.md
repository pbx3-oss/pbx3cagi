# Contributing to PBX3

Thanks for helping improve PBX3. Product code lives under the [pbx3-oss](https://github.com/pbx3-oss) organization. Operator docs: [pbx3-docs](https://pbx3-oss.github.io/pbx3-docs/).

## Before you start

- Read this repo’s root `README.md` for build/run pointers.
- Operator install and architecture: [pbx3-docs](https://pbx3-oss.github.io/pbx3-docs/).
- By submitting, you confirm you have the **right to contribute** what you submit (you own it or are authorized to offer it under the project license).

## Developer Certificate of Origin (DCO)

We use the [DCO](https://developercertificate.org/) instead of a CLA.

Every commit must include:

```text
Signed-off-by: Your Name <your@email.example>
```

Git shortcut:

```bash
git commit -s -m "Your message"
```

Your sign-off certifies the DCO (you have the right to submit the work under the project license).

## Pull requests

1. Fork (or use a branch with write access).
2. Create a focused branch; keep PRs small and reviewable.
3. Open a PR against `main`. Describe **why**, not only what.
4. Ensure any existing checks pass. Add or update tests when practical.
5. Maintainers review and merge. Open source ≠ automatic merge.

Direct pushes to `main` are restricted; use PRs.
